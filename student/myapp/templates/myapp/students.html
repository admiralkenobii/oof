Демонстрация Django ORM

Django ORM позволяет работать с базой данных с помощью Python-кода, не записывая SQL-запросы напрямую.

Ниже один и тот же набор моделей используется для демонстрации различных возможностей ORM.

1. Получение объектов

1. Все объекты — all()

Student.objects.all()

Возвращает QuerySet со всеми студентами.

    {% for student in students_all %}
  • {{ student.last_name }} {{ student.first_name }} {{ student.middle_name }}
    • {% empty %}
  • Студентов нет
    • {% endfor %}

2. Получение одного объекта — get()

Student.objects.get(id=1)

Метод get() используется, когда ожидается ровно один объект.

{% if student_get %}

Найден студент: {{ student_get.last_name }} {{ student_get.first_name }} {{ student_get.middle_name }}

{% else %}

Студент с id = 1 не найден.

{% endif %}

Если объект не найден, Django вызывает DoesNotExist.

Если найдено несколько объектов, Django вызывает MultipleObjectsReturned.

3. Первый и последний объект — first() / last()

            Student.objects.order_by("last_name").first()
            Student.objects.order_by("last_name").last()
{% if student_first %}

Первый: {{ student_first.last_name }} {{ student_first.first_name }}

{% endif %} {% if student_last %}

Последний: {{ student_last.last_name }} {{ student_last.first_name }}

{% endif %}

4. Количество объектов — count()

Student.objects.count()

Всего студентов: {{ students_count }}

2. Фильтрация

5. Фильтрация — filter()

            Student.objects.filter(group__name="410")

Выбираем студентов, которые относятся к группе 410.

    {% for student in students_filter %}
  • {{ student.last_name }} {{ student.first_name }} — {{ student.group.name }}
    • {% empty %}
  • Студентов этой группы нет
    • {% endfor %}

6. Исключение — exclude()

            Student.objects.exclude(group__name="410")

Получаем всех студентов, кроме студентов группы 410.

    {% for student in students_exclude %}
  • {{ student.last_name }} {{ student.first_name }} — {{ student.group.name }}
    • {% empty %}
  • Студентов нет
    • {% endfor %}

7. Поиск по части строки — icontains

Student.objects.filter(
    last_name__icontains="ов"
)

Ищем студентов, в фамилии которых встречается строка "ов". Регистр не учитывается.

    {% for student in students_contains %}
  • {{ student.last_name }} {{ student.first_name }}
    • {% empty %}
  • Студенты не найдены
    • {% endfor %}

8. Проверка в списке — __in

Student.objects.filter(
    group__name__in=["410", "416"]
)

Получаем студентов сразу из нескольких групп.

    {% for student in students_in %}
  • {{ student.last_name }} {{ student.first_name }} — {{ student.group.name }}
    • {% empty %}
  • Студентов нет
    • {% endfor %}

9. Сложные условия — Q()

Student.objects.filter(
    Q(group__name="410") |
    Q(group__name="416")
)

Объект Q позволяет создавать сложные условия и объединять их.

| — OR
& — AND
~ — NOT

    {% for student in students_q %}
  • {{ student.last_name }} {{ student.first_name }} — {{ student.group.name }}
    • {% empty %}
  • Студентов нет
    • {% endfor %}

3. Сортировка и выбор полей

10. Сортировка — order_by()

Student.objects.order_by(
    "last_name",
    "first_name"
)

Сначала сортировка выполняется по фамилии, затем внутри одинаковых фамилий — по имени.

Для сортировки по убыванию используется знак -. 

Student.objects.order_by("-last_name")
    {% for student in students_ordered %}
  1. {{ student.last_name }} {{ student.first_name }}
    2. {% endfor %}

11. Выбор отдельных полей — values()

Student.objects.values(
    "last_name",
    "first_name",
    "student_email",
)

Вместо объектов Student возвращаются словари с указанными полями.

{% for student in students_values %} {% endfor %}
Фамилия Имя Email
{{ student.last_name }} {{ student.first_name }} {{ student.student_email }}

12. Получение кортежей — values_list()

Student.objects.values_list(
    "last_name",
    "first_name",
)

Метод возвращает кортежи, а не словари.

    {% for last_name, first_name in students_values_list %}
  • {{ last_name }} {{ first_name }}
    • {% endfor %}

4. Работа со связями между моделями

13. ForeignKey — select_related()

Student.objects.select_related("group")

Используется для эффективной загрузки связанного объекта по ForeignKey.

Связь: 

Student → Group
{% for student in students_select_related %} {% endfor %}
Студент Группа
{{ student.last_name }} {{ student.first_name }} {{ student.group.name }}

14. ManyToMany — prefetch_related()

Student.objects.prefetch_related(
    "disciplines"
)

Используется для предварительной загрузки связанных объектов ManyToMany.

{% for student in students_prefetch %}

{{ student.last_name }} {{ student.first_name }}

    {% for discipline in student.disciplines.all %}
  • {{ discipline.name }}
    • {% empty %}
  • Дисциплин нет
    • {% endfor %}
{% endfor %}

15. Обратная связь — related_name

group.students.all()

В модели Student поле group является ForeignKey на Group.

Благодаря related_name="students" можно двигаться в обратную сторону: 

Group → Student
{% for group in groups %}

Группа {{ group.name }}

    {% for student in group.students.all %}
  • {{ student.last_name }} {{ student.first_name }}
    • {% empty %}
  • Студентов нет
    • {% endfor %}
{% endfor %}

16. ManyToMany — студент и дисциплины

student.disciplines.all()

Один студент может изучать несколько дисциплин, а одна дисциплина может изучаться несколькими студентами.

{% for student in students_disciplines %}

{{ student.last_name }} {{ student.first_name }}

    {% for discipline in student.disciplines.all %}
  • {{ discipline.name }} — {{ discipline.semester }} семестр
    • {% empty %}
  • Дисциплин нет
    • {% endfor %}
{% endfor %}

5. Агрегация и вычисления

17. Вычисляемое поле — annotate()

Student.objects.annotate(
    discipline_count=Count("disciplines")
)

Для каждого студента вычисляется количество дисциплин.

Поля discipline_count нет в модели Student. Оно добавляется к результату QuerySet.

{% for student in students_annotated %} {% endfor %}
Студент Количество дисциплин
{{ student.last_name }} {{ student.first_name }} {{ student.discipline_count }}

18. Общее значение — aggregate()

Student.objects.aggregate(
    total=Count("id")
)

annotate() вычисляет значение для каждого объекта.

aggregate() вычисляет итоговое значение для всего QuerySet.

Всего студентов: {{ students_aggregate.total }}

6. QuerySet и SQL

19. Цепочка QuerySet

Student.objects
    .filter(group__name="410")
    .order_by("last_name", "first_name")

Методы QuerySet можно объединять в цепочку.

Сначала выбираются студенты группы 410, затем результат сортируется.

    {% for student in students_chain %}
  1. {{ student.last_name }} {{ student.first_name }} — {{ student.group.name }}
    2. {% empty %}
  2. Студентов нет
    3. {% endfor %}

20. Какой SQL генерирует Django?

{{ students_sql }}

Django ORM строит SQL-запрос, который затем выполняется базой данных.

Таким образом: 

Python
   ↓
Django ORM
   ↓
QuerySet
   ↓
SQL
   ↓
База данных

7. Проблема N+1 запросов

21. Без prefetch_related()

Student.objects.all()

student.disciplines.all()

Если для каждого студента отдельно обращаться к его дисциплинам, могут возникнуть дополнительные запросы к базе данных.

Упрощённо это выглядит так: 

1 запрос — получить студентов

+
N запросов — получить дисциплины
каждого студента

Итого: 1 + N запросов
{% for student in students_without_prefetch %}

{{ student.last_name }} {{ student.first_name }}

    {% for discipline in student.disciplines.all %}
  • {{ discipline.name }}
    • {% empty %}
  • Дисциплин нет
    • {% endfor %}
{% endfor %}

22. Решение — prefetch_related()

Student.objects.prefetch_related(
    "disciplines"
)

Django заранее загружает связанные дисциплины и использует полученные данные при обращении к student.disciplines.all.

{% for student in students_with_prefetch %}

{{ student.last_name }} {{ student.first_name }}

    {% for discipline in student.disciplines.all %}
  • {{ discipline.name }}
    • {% empty %}
  • Дисциплин нет
    • {% endfor %}
{% endfor %}
